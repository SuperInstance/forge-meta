# forge-meta

> The registry that knows about every forge-* crate.

15 crates in the ForgeFlux ecosystem. This one knows them all — what they decompose, how many tests they have, and how to wire them into pipelines. Ask it "what handles CSV?" and it gives you forge-data and forge-flux. Ask for a pipeline suggestion and it builds one.

281+ tests across the ecosystem. The fleet is the graph. The math is conservation.
